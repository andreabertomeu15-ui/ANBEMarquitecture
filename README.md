# ANBEMarquitecture
oficina de ai per als meus estudis universitàris d'arquitectura

## Oficina en 3D
`index.html` és l'oficina en 3D (three.js): set agents amb el seu nom, la seva taula i un full de paper per cada tasca oberta. Clica una taula per veure-hi la feina.

Per veure-la en línia: **Settings → Pages → Deploy from a branch → `main` / root**. Quedarà a `https://andreabertomeu15-ui.github.io/ANBEMarquitecture/`.
